# v2.3 小程序图标与站内通知样式

只改小程序界面，服务器和接口没有变化。

## 图标

全部图标从手绘线条换成 [Remix Icon](https://remixicon.com) 4.6.0（Apache License 2.0，可免费商用）。
路径数据在 `miniprogram/utils/icons.js`，图标名不变，调用处不用改；底部导航选中时用实心版本。
微信标志和登录页的几个实心图标（`wechat`、`wx-*`）保持原样。

## 站内通知（B 图标列表）

同一处的通知收进一张白卡片，每条 = 圆形底色图标 + 标题 + 说明 + 右侧或下方按钮。公共样式是 `app.wxss` 里的 `.nb-*`。

| 位置 | 通知 |
| --- | --- |
| 首页 | 开启工单提醒 |
| 主管首页 | 账号待审批 |
| 销售首页 | 等我处理的收费 |
| 工程师首页 | 待我确认的转交 |
| 工单详情 | 只能查看、缺卡 / 距离异常、转交待确认、待审批的申请、被驳回的结果、暂停搁置 |

小程序版本号 2.3.0。
