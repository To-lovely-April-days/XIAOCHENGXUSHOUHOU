# v2.4 安装调试工单

建单时先选工单种类：**维修工单**（原有的）或**安装调试**（新增）。

## 规则

| 项目 | 安装调试工单 |
| --- | --- |
| 谁能建 | 售后工程师、售后主管；销售没有这一项 |
| 谁负责 | 工程师建的归本人；主管建单时必须指定一位工程师。建完直接「待启动」，不进接单大厅 |
| 换人 | 工程师不能转交；主管可以改派、加协助人 |
| 服务方式 | 固定上门（客户地址必填并在地图上选点），没有「升级服务方式」 |
| 收费 | 不收费：建单时价格记为 0，不走收费确认 |
| 填写内容 | 客户基本信息、设备资料与维修工单相同；不填故障信息，改为选填的「安装说明」 |
| 附件 | 新增两类：送货单（选填）、验收报告（客户签字版，提交完工前必须有） |
| 完工 | 安装调试情况、遗留问题（选填）、设备运行状况、现场照片、验收报告 |
| 其他 | 到场 / 离场打卡、每日工作内容、主管验收闭环照常 |

送货单、验收报告只能传到安装调试工单；安装调试工单不能传维修登记表。

## 界面

- 小程序「新建工单」顶部多了「维修工单 / 安装调试」。
- 「全部工单」（销售 / 主管）和「我的工单」（工程师）顶部分成两个页签，各带数量；安装调试页签没有「待认领」。
- 工单详情：状态旁带「安装调试」标签，价格显示「不收费」，「打卡记录 / 进度」里有验收报告和送货单的上传卡片。
- 电脑后台：工单列表加「工单种类」筛选，类型一列显示「安装调试」；导出表末尾加「工单种类」一列。电脑后台的新建工单仍只建维修工单。

## 接口

- `POST /api/orders` 增加 `kind`（`Install`）、`installNote`、`assigneeId`。
- `POST /api/orders/{id}/complete` 增加 `installSummary`、`openIssues`、`acceptanceIds`。
- `GET /api/orders`、`/mine`、`/created` 增加 `kind` 参数；`counts` 里多 `repair`、`install`。
- 工单 DTO 增加 `kind`、`kindText`；附件类别增加 `DeliveryNote`、`AcceptanceReport`。

## 数据库

迁移 `V24_OrderKind`：`WorkOrders` 加 `Kind`（旧数据都是 `Repair`）、`OpenIssues`。
