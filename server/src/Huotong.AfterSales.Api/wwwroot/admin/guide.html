怎么注册、怎么登录

下面的手机会自己操作一遍，照着做就行。可以随时暂停，也可以点右边的步骤直接跳过去看。

    常见情况

    登录时提示“账号正在审核中”
    注册已经提交，主管还没审批。把你注册的手机号告诉售后主管，请他在电脑后台的“账号管理”里通过。
    登录时提示“注册申请未通过”
    提示里会写原因。点“修改后重新提交”，按原因改好再提交一次。
    提示“手机号或密码错误”
    先核对手机号。连续输错 5 次会锁 10 分钟。主管帮你建的账号如果还没设密码，也会是这个提示，请主管设置一下。
    忘记密码
    请售后主管在电脑后台“账号管理”里点“重置密码”。登录后可以在“我的 → 修改密码”里改成自己的。
    提示“该手机号已有账号”
    说明主管已经帮你建过账号，不用注册。回到登录页，用手机号和密码直接登录。
    换了手机
    在新手机上用同样的手机号和密码登录，再开启一次工单提醒，提醒就会发到新手机。
